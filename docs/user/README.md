# UnclutterPlus 用户指南

## 🚀 快速开始

UnclutterPlus 是一款现代化的 macOS 生产力工具，集成了文件管理、剪贴板历史、Markdown笔记和截图功能。

## 📋 主要功能

### 🗂️ 文件管理
- **智能文件收藏**：支持拖拽操作，快速访问常用文件
- **多视图模式**：网格和列表视图，支持文件排序和搜索
- **快速操作**：右键菜单支持打开和显示在Finder中

### 📋 剪贴板历史
- **企业级存储**：持久化保存剪贴板历史记录
- **智能类型识别**：自动识别文本、图片、文件类型
- **高级搜索**：全文搜索，支持实时过滤
- **性能优化**：最近项目访问时间 <100ms

### 📝 Markdown笔记
- **实时编辑器**：基于SwiftUI的现代化编辑器，支持实时预览
- **完整语法支持**：使用Splash进行代码语法高亮
- **智能存储**：标签管理，搜索和收藏功能

### 📸 截图管理
- **OCR集成**：Deepseek OCR引擎文字识别
- **智能截图**：支持区域选择和标注功能
- **组织化存储**：自动分类和搜索功能

## ⚙️ 快速安装

1. **下载**：从 [GitHub Releases](https://github.com/voidzyh/UnclutterPlus/releases) 下载
2. **安装**：打开DMG文件，将应用拖拽到应用程序文件夹
3. **启动**：从启动台或应用程序启动

## 🔧 开发指南

### 开发环境
- **要求**：macOS 14.0+，Xcode 15+，8GB+ RAM
- **依赖**：Swift 6.0，SwiftUI 5.0，Combine
- **包管理**：Swift Package Manager

### 架构概览
- **MVVM架构**：清晰的视图-视图模型分离
- **统一存储**：基于Repository模式的统一存储协议
- **现代设计系统**：一致的视觉语言和交互

### 贡献指南
- **代码风格**：遵循Swift标准格式化规范
- **测试要求**：维持>80%测试覆盖率
- **提交规范**：使用Conventional Commits
