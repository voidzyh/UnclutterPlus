# 浮动面板真机回归清单（2026-08）

对应 backlog P0 验收项「浮动面板全链路稳定（唤出/隐藏/自动隐藏/多屏定位）」与「面板唤出速度与内存占用达标」。代码侧已埋性能打点（`logger.performance`），本清单在真机上过一遍功能项并采集性能数据。

## 采集方法

性能日志走 os_log（子系统 `com.unclutterplus`，分类 `Performance`，info 级，Debug/Release 构建均可见）。回归开始前在终端常驻：

```bash
log stream --predicate 'subsystem == "com.unclutterplus" AND category == "Performance"' --info
```

性能项每项连测 5 次取中位数记录。功能项若失败，记入文末缺陷表（附复现步骤与日志）。

## 一、功能回归

### 唤出路径（6 条入口都要能唤出，位置：当前鼠标所在屏顶部居中）

- [ ] 全局快捷键 ⌘⇧U 唤出；面板可见时再按为隐藏（切换语义）
- [ ] 菜单栏图标单击唤出/隐藏（含涟漪反馈）
- [ ] 菜单栏菜单「打开面板」菜单项
- [ ] 菜单栏边缘滚动唤出/隐藏（按设置的滚动方向映射）
- [ ] Dock 图标点击唤出
- [ ] Shortcuts「显示/隐藏面板」intent

### 隐藏路径

- [ ] Esc 键隐藏（面板可见且非编辑态）
- [ ] 动作后自动隐藏：复制剪贴板项 / 打开暂存文件 / Finder 揭示后约 0.5s 收起（设置开启时）
- [ ] 失焦自动隐藏：点击其他应用后按设置的延迟收起（设置开启时）

### 自动隐藏守卫（设置「失焦隐藏」开启时验证不误隐藏）

- [ ] 面板内编辑笔记时点击其他应用 → 不隐藏
- [ ] 从面板拖拽文件到外部应用过程中 → 不隐藏
- [ ] 设置窗口打开期间 → 面板不因失焦隐藏

### 键盘流（唤出后焦点正确性）

- [ ] 唤出后无需点击即可直接打字搜索
- [ ] ↑↓ 移动高亮、回车复制并自动隐藏

### 多屏定位（条件项：无外接屏则整组标 N/A 留待后续）

- [ ] 主屏唤出贴顶部居中、不越屏边界
- [ ] 鼠标移到副屏后唤出，面板跟随副屏
- [ ] 副屏在主屏上方的布局：面板顶部留出间隔（降级偏移）
- [ ] 缩放比例不一致的双屏组合下位置正确
